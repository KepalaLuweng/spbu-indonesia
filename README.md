# SPBU Indonesia API (Open Data)

Dataset dan API Terbuka Lokasi SPBU Pertamina di 38 Provinsi Indonesia. Dibuat dan dikelola oleh **KepalaLuweng / LuwengGroup** untuk mendukung aplikasi Catet dan ekosistem publik.

## Statistik Database:
- **Total SPBU Nasional:** 6.290+ SPBU
- **Cakupan Wilayah:** 38 Provinsi di Seluruh Indonesia
- **Sumber Data:** OpenStreetMap (OSM) Contributor & Verifikasi Koridor Utama Jalur Logistik Nasional

## Struktur Endpoint:
- **Daftar 38 Provinsi (Index):**
  `https://raw.githubusercontent.com/KepalaLuweng/spbu-indonesia/main/v1/index.json`
- **Data Per Provinsi (Contoh DKI Jakarta):**
  `https://raw.githubusercontent.com/KepalaLuweng/spbu-indonesia/main/v1/provinces/dki-jakarta.json`

## Fitur Data:
- Koordinat GPS Presisi (Latitude & Longitude)
- Alamat Lengkap & Kota/Kabupaten
- Fasilitas SPBU (Musholla, Toilet, ATM, Nitrogen, Bright Store/Minimarket)
- Daftar Jenis BBM Tersedia (Pertalite, Pertamax, Pertamax Turbo, Dexlite, Solar/BioSolar)
- Status Operasional 24 Jam
