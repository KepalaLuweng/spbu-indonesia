# SPBU Indonesia API (Open Data)

Dataset dan API Terbuka Lokasi SPBU Pertamina di 38 Provinsi Indonesia. Dibuat dan dikelola oleh **KepalaLuweng / Luweng Studios** untuk mendukung aplikasi Catet dan ekosistem publik.

## Struktur Endpoint:
- **Daftar 38 Provinsi (Index):**
  `https://raw.githubusercontent.com/KepalaLuweng/spbu-indonesia/main/v1/index.json`
- **Data Per Provinsi (Contoh DKI Jakarta):**
  `https://raw.githubusercontent.com/KepalaLuweng/spbu-indonesia/main/v1/provinces/dki-jakarta.json`

## Fitur Data:
- Koordinat GPS (Latitude & Longitude)
- Alamat Lengkap & Kota/Kabupaten
- Fasilitas SPBU (Musholla, Toilet, ATM, Nitrogen, Minimarket)
- Daftar Jenis BBM Tersedia (Pertalite, Pertamax, Turbo, Dexlite, Solar)
- Status Operasional 24 Jam
